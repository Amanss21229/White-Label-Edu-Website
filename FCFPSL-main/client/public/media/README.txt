PUT YOUR SLIDER MEDIA FILES IN THIS FOLDER
========================================
Upload images/videos here through GitHub, then reference them in Render's BRAND_HERO_MEDIA variable.

Examples (use the exact filename and your deployed site domain):
Image URL: /media/image1.jpg
Video URL: /media/video1.mp4

Supported examples: .jpg, .jpeg, .png, .webp, .mp4, .webm
Keep individual files reasonably small for faster loading. GitHub browser uploads are limited by file size.
For each item, set type to "image" or "video", url to the public URL (e.g. https://YOUR-SITE.onrender.com/media/image1.jpg), and link to the destination for Explore.
